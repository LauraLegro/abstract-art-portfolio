# Abstract Visions

A single-page abstract photography portfolio with a parallax hero section and a 52-photo gallery, all hotlinked from Unsplash.

**Live site:** https://lauralegro.github.io/abstract-art-portfolio/

## Features

- Animated gradient/blob background
- Multi-column masonry-style photo gallery with hover zoom, caption reveal, and glow effects
- Scroll-based parallax via `data-speed` attributes

## Running locally

No build step — it's a single `index.html`. Either open it directly in a browser, or serve it:

```
python3 -m http.server
```
